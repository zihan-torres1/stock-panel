买点、卖点是什么意思？（点开看完整清单）
买点 · 7 项（命中几项就是「买点 n/7」）
  1. MACD金叉 — 快线从下向上穿越慢线，下跌动能转成上涨动能
  2. 底背离 — 股价创新低但MACD没创新低，跌不动了
  3. KDJ低位金叉 — KDJ在超卖区金叉，短期跌过头了开始有人接
  4. 放量上涨 — 成交量放大且股价上涨，有真金白银进场
  5. 龙回头 — 涨停后缩量回踩支撑，强势股的第二波机会
  6. 回踩布林下轨 — 跌到布林下轨被接住，短线超跌反弹
  7. 5日上穿10日 — 5日均线上穿10日均线，短线转强
卖点 · 5 项（命中几项就是「卖点 n」）
  1. 顶背离 — 股价创新高但MACD没创新高，涨不动了
  2. 量增价滞 — 成交量放大但价格不涨，有人在借机出货
  3. 无量拉升 — 股价在涨但没成交量，虚涨，容易跌回去
  4. 跌破10日线 — 跌穿短线强弱分界，趋势走坏
  5. KDJ高位死叉 — 超买区死叉，短期回调概率高
怎么用：书里那句话是关键——单一指标只用来验证想法，多个指标同时出现（共振）才是真正的时机。
所以：买点 ≥2 且卖点 =0 → 才算「时机到了」，可以小仓试；
　　　买点 0~1 → 只是「有点苗头」，继续等；
　　　卖点 ≥1 → 无论买点多少，先处理风险。
